# Travidy: Your Travel Companion

Design a fully functional Travidy mobile app based on this information attached. I will focus on three core pages: Landing Page, Chatbot Page, and Itinerary & Checklist Page.

Context: Travidy (Travel buddy) is a travel companion that plans, walks side-by-side with the traveller during the trip and shares all travel content while making the experience available for the next traveller. 

It should be able to be linked with supabase. Use the designs given
